This is a Node.js and Express application that fetches random secrets from the Secrets API and displays them using EJS.

## Features

- Fetch random secret from API
- Display secret and username
- Uses Express and Axios
- Uses EJS templating

## Tech Stack

- Node.js
- Express.js
- Axios
- EJS
- CSS

## Setup

1. Clone repository

2. Install dependencies
npm install

3. Create .env file
TOKEN=your_token
PORT=3000

4. Run app
node index.js

5. Open browser
http://localhost:3000
